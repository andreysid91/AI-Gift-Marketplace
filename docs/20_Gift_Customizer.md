# Gift Customizer — Конструктор персонального подарка

## Цель

Дать пользователю возможность создать уникальный подарок без блуждания по каталогу.

Пользователь не выбирает просто товар.

Он создаёт идею подарка — AI показывает дизайны сразу на разных изделиях и помогает собрать набор.

---

# Основной сценарий

Пользователь:

1. Описывает идею подарка или пишет «Хочу подарок брату».
2. Загружает фотографии (по желанию).
3. Получает несколько стилей дизайна от AI.
4. Видит один дизайн сразу на разных товарах.
5. Выбирает товар и меняет состав набора.
6. Добавляет упаковку, открытку и дополнения.
7. Оставляет заявку / получает расчёт.
8. На MVP — связь с клиентом; далее — оплата и производство.

---

# Работа с фотографиями

Пользователь может:

* загрузить одну фотографию;
* загрузить несколько фотографий;
* удалить фотографии;
* изменить порядок;
* выбрать назначение фотографии.

Пример:

Фото №1:

Использовать:

* кружка
* футболка

Фото №2:

Использовать:

* холст
* гравировка

Фото №3:

Использовать:

* магнит

---

# Добавление элементов

Пользователь может добавить:

* текст;
* дату;
* имя;
* цитату;
* логотип;
* открытку;
* упаковку;
* дополнительный товар.

---

# Свободное описание

Поле:

"Опишите, что вы хотите получить"

Пример:

"Сделайте подарок жене на годовщину. Используйте наши фотографии, добавьте дату свадьбы и красивую надпись."

ИИ анализирует текст и формирует техническое задание.

---

# Стили дизайна

AI создаёт несколько вариантов, например:

* карикатура
* Pixar
* комикс
* акварель
* масляная живопись
* поп-арт
* минимализм
* неон
* карандаш
* ретро
* винтаж

---

# Один дизайн — много товаров

Выбранный дизайн автоматически показывается на:

* кружке
* футболке
* холсте
* магните
* пазле
* фотокниге

и других доступных изделиях по технологиям партнёров.

Пользователь сразу видит готовый подарок.

---

# Варианты производства

ИИ предлагает разные способы с учётом технологий:

Пример одной фотографии:

* Вариант 1: кружка (сублимация)
* Вариант 2: холст (фотопечать)
* Вариант 3: гравировка на дереве
* Вариант 4: подарочный набор

---

# Карточка подарка

Каждый вариант содержит:

* название;
* стиль дизайна;
* мокапы на товарах;
* описание;
* что входит в набор;
* примерную цену;
* срок;
* кнопку изменить.

# Изменения заказа

До оплаты клиент может:

* добавлять товары;
* менять фотографии;
* менять текст;
* добавлять пожелания.

После оплаты изменения проходят через подтверждение.

---

# Главная идея

Не продавать готовый товар из каталога.

Создать систему:

Идея клиента → AI → стили дизайна → мокапы на товарах → набор → заявка → производство → вручение.
