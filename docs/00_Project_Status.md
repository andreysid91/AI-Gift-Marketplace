# Цель MVP

Максимально простой путь:

1. Главная.
2. Поиск подарка (текст или фото).
3. Красивые варианты.
4. Выбор товара.
5. Дополнительные товары.
6. Заявка.
7. Связь с клиентом.

Без лишних экранов и сложных анкет.

---

# Первая версия не включает

* автоматическое подключение всех партнёров;
* личные кабинеты партнёров;
* полный спектр технологий в самообслуживании;
* сложную CRM;
* мобильное приложение;
* автоматическую логистику;
* цветы и воздушные шары (только закладка в архитектуру).
