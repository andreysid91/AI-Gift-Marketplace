# Gift Knowledge Base — База знаний AI Gift

## Назначение

Это **главный справочный документ** проекта для подбора подарков.

Документ предназначен для:

* AI Gift Brain;
* Gift Engine;
* менеджеров и партнёров;
* будущей автоматизации рекомендаций.

AI должен использовать эту базу как основу решений:

запрос / фото → получатель → повод → интересы → стиль → товары → набор → технология → партнёр.

---

## Как AI читает эту базу

1. Определить **получателя**.
2. Определить **повод**.
3. Извлечь **интересы** (из текста, фото, уточнений).
4. Выбрать 2–4 подходящих **стиля**.
5. По стилю и категории человека выбрать **товары**.
6. Собрать **набор** (основной товар + дополнения).
7. Проверить доступность по **технологии** и партнёрам.
8. Показать готовые варианты, а не каталог.

Правило: никогда не предлагать товар, который нельзя произвести.

* Минимализм → универсален, особенно для B2B и сдержанных получателей.

# 9. Возможные подарочные наборы

Формула набора:

**Основной товар + упаковка + открытка (+ подпись) + 1–3 дополнения**

## 9.1. Универсальные наборы

| Набор | Состав | Когда предлагать |
|---|---|---|
| Классика | кружка + упаковка + открытка + шоколад | быстрый универсальный подарок |
| Уют | кружка + свеча + чай + открытка | мама, девушка, домашний вечер |
| Кофеман | кружка/термокружка + кофе + открытка | интерес к кофе |
| Память | холст + рамка + открытка | годовщина, семья |
| Яркий день | футболка + магнит + сладости | др друга/подруги |
| Семейный | фотокнига + магниты + открытка | родители, дети, праздники |
| Премиум | холст + гравировка + премиум-упаковка | статусный повод |

## 9.2. Наборы по получателю

* **Девушке:** холст/кружка + свеча + шоколад + открытка
* **Маме:** фотокнига/холст + чай + открытка
* **Папе:** термос или гравировка + кофе + открытка
* **Ребёнку:** пазл или футболка + мягкая игрушка + сладости
* **Брату/другу:** футболка или кружка (карикатура/комикс) + шоколад

## 9.3. Правила сборки для AI

1. Сначала выбрать 1 основной товар.
2. Всегда предлагать упаковку и открытку как усиление.
3. Добавлять 1–2 дополнения по интересам (не всё сразу).
4. Следить, чтобы набор выглядел цельным на одной сцене.
5. Будущие позиции (цветы, шары, торты) подключать только при доступности партнёра.

# 10. Корпоративные сценарии

| Сценарий | Запрос-пример | Решение | Технологии |
|---|---|---|---|
| Подарки сотрудникам | «подарки отделу на НГ» | единый набор 2–3 уровней бюджета | сублимация, текстиль, упаковка |
| Подарки клиентам | «комплимент клиентам» | мини-набор + брендирование | кружка/открытка/шоколад |
| Подарки партнёрам | «статусный подарок партнёру» | премиум-набор + гравировка | гравировка, холст, упаковка |
| Welcome-box | «наборы новым сотрудникам» | шоппер/кружка + блокнот/ручка + открытка | текстиль, сублимация, полиграфия |
| Новогодние наборы | «100 новогодних боксов» | единый дизайн + тираж + упаковка | несколько технологий + комплектация |
| Корпоративный мерч | «футболки и кружки с логотипом» | единый бренд-стиль, размерная сетка | текстиль, сублимация |
| Массовый тираж | «50 одинаковых подарков» | образец → согласование → производство | по доступным партнёрам |

### Правила B2B для AI

* Предлагать **единый визуальный стиль** на весь тираж.
* Давать 2–3 варианта бюджета (эконом / стандарт / премиум).
* Учитывать срок: массовые заказы требуют запаса по времени.
* На MVP корпоратив идёт через заявку и менеджера.

Подробнее: `17_Corporate_Gifts.md`.

# Алгоритм подбора (для AI)

```
Вход: текст и/или фото
  ↓
Определить получателя (раздел 1)
  ↓
Определить повод (раздел 2)
  ↓
Извлечь интересы (раздел 3)
  ↓
Выбрать 3–5 стилей (разделы 6–7)
  ↓
Подобрать товары под человека и стиль (разделы 5, 7, 8)
  ↓
Проверить технологии и доступность (раздел 4)
  ↓
Собрать 2–4 готовых варианта + наборы (раздел 9)
  ↓
Если B2B — применить корпоративные сценарии (раздел 10)
  ↓
Показать готовые подарки на сцене / мокапах
```
