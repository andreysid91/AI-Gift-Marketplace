# BUG_REPORT — UX-аудит (TASK-075)

Аудит клиентского фронтенда (`frontend/`). Внутренние кабинеты (admin / owner / partner / warehouse) не оценивались, кроме утечек в клиентский UI.

Дата: 2026-08-06.

---

## Critical

### C1. «Заказать такой же» = просто страница подарка
- **Где:** главная · `HomeLatestOrders` · `lib/trust/seed.ts` (`orderSameHref` === `giftHref`)
- **Проблема:** CTA обещает заказ, но открывает `/gift` без префилла корзины/checkout.
- **Решение:** перед переходом сохранять `GiftOrder` и вести на `/checkout?from=gift&id=…`.
- **Статус:** исправлено

### C2. Отзывы обещают «заказать такой же», ведут только на Gift Page
- **Где:** `/reviews`, `HomeReviews`
- **Проблема:** копирайт не совпадает с действием.
- **Решение:** явное «К подарку» + отдельное «Заказать такой же» с префиллом (см. C1).
- **Статус:** исправлено

### C3. Фотопечать «Заказать» — демо без отправки
- **Где:** `/photo/[slug]` · `PhotoProductView`
- **Проблема:** после загрузки фото — тупик «Пока демо», нет checkout.
- **Решение:** сохранить черновик и перейти в `/checkout` (или `/contact` с контекстом).
- **Статус:** исправлено

### C4. «Для бизнеса» — кнопка расчёта никуда не ведёт
- **Где:** `/business` · `BusinessDirectionView`
- **Проблема:** локальный toast / демо, хаб «Для бизнеса» обрывается.
- **Решение:** вести в `/create?scenario=corporate` (и/или `/contact`).
- **Статус:** исправлено

### C5. Checkout без sessionStorage молча подставляет чужой подарок
- **Где:** `/checkout` · `GiftCheckoutExperience`
- **Проблема:** пустая корзина + `from=gift` → `MOCK_IDEAS[0]` без предупреждения.
- **Решение:** если нет заказа и нет `id` — экран «корзина пуста»; при наличии `id` — черновик из товара.
- **Статус:** исправлено

### C6. Ideas → checkout без id в URL
- **Где:** `GiftPickerView`
- **Проблема:** зависимость только от sessionStorage; новая вкладка ломает заказ.
- **Решение:** передавать `id` первого товара в query checkout.
- **Статус:** исправлено

### C7. Контактная форма выглядит как принятый заказ
- **Где:** `/contact` · `IdeaForm`
- **Проблема:** «Спасибо, свяжемся», файлы не уходят — ложное ощущение заявки.
- **Решение:** честный текст + сохранение заявки в localStorage / явный статус.
- **Статус:** исправлено
