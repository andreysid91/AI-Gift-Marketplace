# Roadmap

## Этап 1 — MVP (Красноярск)

□ Исследовать партнёров по технологиям
□ Собрать базу: технологии / товары / цены / сроки
□ Сделать MVP сайта (простой путь: поиск → варианты → заявка)
□ Показать дизайны на товарах MVP
□ Принимать заявки и связываться с клиентом
□ Получить первый заказ
□ Выполнить первый заказ вручную
