# 05. Gift Scenarios — Библиотека сценариев

## Назначение

Библиотека готовых сценариев подбора подарка.

Сценарий — шаблон для AI:

**получатель + повод + интересы → стили + товары + дополнения**

AI сначала ищет близкий сценарий, затем адаптирует под запрос и фото.

---

## Модель данных (сценарий)

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Код сценария |
| `recipient` | string | Получатель |
| `occasion` | string | Повод |
| `interests` | string[] | Интересы |
| `styles` | string[] | Предлагаемые стили |
| `products` | string[] | Предлагаемые товары |
| `addons` | string[] | Дополнительные товары |
| `bundle_example` | string | Пример набора |
| `notes` | text | Подсказки AI |

---

## Как AI использует библиотеку

1. Извлекает получателя, повод, интересы.
2. Находит 1–3 ближайших сценария.
3. Берёт из них стили, товары и дополнения.
4. Адаптирует под фото и бюджет.
5. Проверяет доступность технологий у партнёров.
6. Показывает готовые варианты.
