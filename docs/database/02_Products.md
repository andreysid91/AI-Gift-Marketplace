# 02. Products — Каталог товаров

## Назначение

Полный каталог возможных товаров экосистемы AI Gift.

Цены и сроки — **ориентиры для архитектуры данных** (Красноярск, ₽).
Фактические значения берутся из карточек партнёров.

---

## Модель данных (товар)

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Уникальный код, напр. `PRD_MUG_WHITE` |
| `name` | string | Название |
| `category_id` | string | Ссылка на категорию |
| `technology` | string | Технология изготовления |
| `photo_compatible` | bool | Можно изготовить по фотографии |
| `ai_design_compatible` | bool | Можно изготовить по AI-дизайну |
| `price_avg` | number | Средняя цена для клиента |
| `price_min` | number | Минимальная цена |
| `price_max` | number | Максимальная цена |
| `cost_avg` | number | Средняя себестоимость |
| `lead_time_avg_days` | number | Среднее время изготовления (дни) |
| `is_addon` | bool | Дополнительный товар |
| `is_mvp` | bool | Входит в MVP |
| `status` | enum | `active` \| `manual` \| `future` |

## Индексы и связи

```
Product.category_id → Category.id
Product *—* Partner (через PartnerProduct)
Product *—* AIStyle (через StyleProductFit)
Product 1—* BundleItem
```

## Правило для AI

Предлагать в автоматическом потоке только товары с `is_mvp = true` или `status = active`.
Товары `manual` может добавить менеджер при сборке заказа.
