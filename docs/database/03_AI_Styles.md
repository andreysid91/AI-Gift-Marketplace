# 03. AI Styles — Каталог AI-стилей

## Назначение

Справочник визуальных стилей, которые AI генерирует для подарков.

Каждый стиль содержит:

* описание;
* характер;
* список товаров, на которых стиль хорошо смотрится;
* рекомендации по получателям и поводам.

---

## Модель данных (стиль)

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Код, напр. `STYLE_PIXAR` |
| `name` | string | Название |
| `description` | text | Описание стиля |
| `mood` | string | Эмоциональный характер |
| `best_products` | string[] | Товары, где стиль смотрится лучше всего |
| `good_products` | string[] | Допустимые товары |
| `best_for` | string[] | Получатели / поводы |
| `avoid_for` | string[] | Когда не предлагать |
| `is_mvp` | bool | Доступен в MVP |

| Поле | Значение |
|---|---|

## Правила выдачи для AI

1. На один запрос показывать **3–5 стилей**, не весь каталог.
2. Всегда включать минимум один «безопасный» стиль (акварель / минимализм / Pixar — по контексту).
3. Один выбранный стиль сразу показывать на нескольких товарах.
4. Не предлагать стиль, который плохо совместим с выбранным товаром.
