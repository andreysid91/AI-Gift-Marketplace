# 01. Gift Categories — Категории подарков

## Назначение

Справочник категорий верхнего уровня для каталога, AI-подбора и карточек партнёров.

Категория отвечает на вопрос:

**каким способом / в каком контуре производится или собирается подарок?**

---

## Модель данных (категория)

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Уникальный код, напр. `CAT_PHOTO` |
| `name` | string | Название категории |
| `slug` | string | URL/ключ |
| `type` | enum | `technology` \| `bundle` \| `b2b` |
| `description` | text | Краткое описание |
| `sort_order` | int | Порядок в админке |
| `is_active_mvp` | bool | Доступно ли в MVP |
| `related_technologies` | string[] | Связанные технологии |


## Правило для AI

Сначала определяется категория/технология, затем конкретный товар.
Набор (`CAT_BUNDLE`) всегда ссылается на один или несколько основных товаров из технологических категорий.
