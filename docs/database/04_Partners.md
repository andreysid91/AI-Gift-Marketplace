# 04. Partners — Карточка партнёра

## Назначение

Структура данных производственного партнёра AI Gift.

Партнёр — скрытый слой производства.
Клиент видит бренд AI Gift, партнёр изготавливает заказ.

---

## Модель данных (партнёр)

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Уникальный код |
| `name` | string | Название |
| `address` | string | Адрес |
| `phone` | string | Телефон |
| `contact_person` | string | Контактное лицо |
| `city` | string | Город |
| `district` | enum | `left_bank` \| `right_bank` \| `other` |
| `technologies` | string[] | Поддерживаемые технологии |
| `products` | ProductRef[] | Товары, которые производит |
| `min_lead_time_days` | number | Минимальный срок изготовления |
| `avg_prices` | object | Средние цены по товарам/услугам |
| `rating` | number | Рейтинг 1.0–5.0 |
| `rush_available` | bool | Возможность срочного изготовления |
| `rush_surcharge_pct` | number | Наценка за срочность, % |
| `max_daily_capacity` | number | Оценка мощности (опционально) |
| `notes` | text | Комментарии менеджера |
| `is_active` | bool | Активен ли для назначения заказов |

---

## Обязательные блоки карточки

### 1. Название

Юридическое или рабочее имя партнёра, как в переговорах и заказах.

Пример: `PrintHouse Красноярск`

---

### 2. Адрес

Фактический адрес производства / пункта приёма макетов.

Нужен для:

* логистики;
* самовывоза менеджером;
* понимания берега и района.

---

### 3. Телефон

Основной номер + желательно мессенджер для оперативной связи.

---

### 4. Технологии

Список технологий из справочника категорий:

* фотопечать
* сублимация
* текстиль
* лазерная гравировка
* вышивка
* UV-печать
* 3D-печать
* упаковка / комплектация

AI и менеджер назначают заказ только партнёру с нужной технологией.

---

### 5. Товары

Список изделий, которые партнёр реально делает, со связью на `Product.id`.

Для каждого товара партнёра желательно хранить:

| Поле | Описание |
|---|---|
| `product_id` | Ссылка на товар |
| `partner_price` | Закупочная / себестоимость для нас |
| `client_price_hint` | Рекомендуемая цена клиенту |
| `lead_time_days` | Срок именно у этого партнёра |
| `min_qty` | Минимальный тираж |
| `examples_url` | Примеры работ |

---

### 6. Минимальный срок изготовления

Самый быстрый реалистичный срок без режима «срочно».

Пример: `1 день` для кружки, `2–3 дня` для футболки.

---

### 7. Средние цены

Сводка по ключевым позициям партнёра.

Пример:

| Товар | Средняя цена партнёра |
|---|---|
| Кружка | 350 ₽ |
| Футболка | 650 ₽ |
| Холст | 900 ₽ |
| Магнит | 100 ₽ |

---

### 8. Рейтинг

Внутренний рейтинг качества и надёжности:

* качество печати / пошива;
* соблюдение сроков;
* коммуникация;
* брак / переделки.

Шкала: `1.0 – 5.0`

---

### 9. Левый / Правый берег

Для Красноярска:

| Значение | Смысл |
|---|---|
| `left_bank` | Левый берег |
| `right_bank` | Правый берег |
| `other` | Другой район / пригород |

Используется для удобной логистики менеджера и курьера.

---

### 10. Возможность срочного изготовления

`rush_available = true/false`

Если да — указать:

* насколько можно ускорить;
* наценку;
* до какого часа принимать срочные заказы.

---

## Пример карточки партнёра

```yaml
id: PTR_KRAS_001
name: PrintHouse Красноярск
address: ул. Примерная, 10
phone: +7 (391) 000-00-00
contact_person: Анна
city: Красноярск
district: right_bank
technologies:
  - sublimation
  - photo_print
  - textile
products:
  - product_id: PRD_MUG_WHITE
    partner_price: 350
    lead_time_days: 1
  - product_id: PRD_TSHIRT
    partner_price: 650
    lead_time_days: 2
  - product_id: PRD_CANVAS
    partner_price: 900
    lead_time_days: 3
min_lead_time_days: 1
avg_prices:
  mug: 350
  tshirt: 650
  canvas: 900
rating: 4.7
rush_available: true
rush_surcharge_pct: 30
is_active: true
notes: Хорошие кружки, футболки брать только утром
```

---

## Логика назначения партнёра (MVP)

1. Менеджер получает заявку.
2. Смотрит нужную технологию и товар.
3. Фильтрует активных партнёров.
4. Учитывает срок, берег, рейтинг, срочность.
5. Передаёт заказ выбранному партнёру.

На следующих этапах AI сможет предлагать партнёра автоматически.
