# Scenario Engine — TASK-060

Каждый пользовательский запрос относится к **одному сценарию**.  
У каждого сценария — **своя** последовательность вопросов.  
Сценарии независимы: новый добавляется в реестр без переписывания ядра.

---

## Сценарии v1

| id | Название |
|----|----------|
| `gift` | Подарок |
| `photo` | Фотопечать |
| `corporate` | Корпоратив |
| `print_3d` | 3D печать |
| `laser` | Лазерная гравировка |
| `embroidery` | Вышивка |
| `unsure` | Не знаю что подарить |
| `custom` | Свой вариант |

---

## Примеры потоков

### Подарок
Кому? → Повод? → Бюджет? → Фото есть? → Готово

### Корпоратив
Что изготовить? → Количество? → Логотип есть? → Срок? → Город? → Готово

---

## Архитектура

```
Запрос
  │
  ▼
classifyScenario()     ← правила из реестра (без AI)
  │
  ▼
ScenarioWizard        ← шаги только этого сценария
  │
  ▼
answersToQuery()      ← обогащённый запрос
  │
  ├─ gift / unsure / photo → /ideas (Gift Engine)
  └─ corporate / tech / custom → экран сценария
```

| Файл | Роль |
|------|------|
| `lib/scenario-engine/registry.ts` | Определения + шаги |
| `lib/scenario-engine/classify.ts` | Авто-классификация |
| `lib/scenario-engine/flow.ts` | Навигация по вопросам |
| `components/scenario-wizard.tsx` | UI мастера |
| `components/create-view.tsx` | Точка входа `/create` |

---

## Как добавить сценарий

1. Добавить id в `SCENARIO_IDS`  
2. Добавить объект в `SCENARIO_REGISTRY` (keywords + `steps`)  
3. При необходимости — ветка результата в `create-view`  

Ядро classify/flow менять не нужно.

---

## Связь с Gift Engine

У сценария есть `orderType`: `gift` | `photo` | `business` | `custom`.  
Gift Engine получает уже обогащённый запрос после мастера.

`analyzeUserIntent` (agent) — тонкий мост к Scenario Engine для старого кода.
