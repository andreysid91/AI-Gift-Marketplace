# Производственные партнёры

## Роль партнёров

Партнёры — скрытый производственный слой AI Gift.

Клиент видит единый бренд.
Партнёр изготавливает заказ по технологии, цене и сроку.

---

## Архитектурный принцип

Платформа строится **вокруг технологий изготовления**.

Каждый партнёр в системе указывает:

| Поле | Описание |
|---|---|
| Технологии | Что умеет производить |
| Товары | Конкретные изделия по технологиям |
| Цены | Себестоимость / прайс для платформы |
| Сроки | Типовое время изготовления |
| Город / зона | Где может выполнять заказы |
| Ограничения | Тиражи, материалы, качество |

AI использует эти данные при подборе подарков и никогда не предлагает то, чего нельзя произвести.

## Как AI выбирает партнёра

1. Определяет нужную технологию и товар.
2. Фильтрует партнёров по городу / зоне.
3. Сравнивает цену и срок.
4. Учитывает рейтинг и загрузку.
5. Передаёт заказ исполнителю.

На этапе MVP заказ может назначаться менеджером вручную.
