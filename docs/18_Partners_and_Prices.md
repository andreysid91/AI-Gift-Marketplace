# Партнеры и цены

## Цель

Создать внутреннюю базу производителей и цен.

Клиент видит только наш сервис.

Партнёры — производственный слой платформы.

Архитектура строится вокруг **технологий изготовления**.

Каждый партнёр указывает:

* какие технологии поддерживает;
* какие товары производит;
* цены;
* сроки изготовления.

AI использует эти данные при подборе подарков.
