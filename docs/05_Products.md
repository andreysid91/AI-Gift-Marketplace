# Каталог продукции

## Принцип

Каталог строится **вокруг технологий изготовления**, а не вокруг случайного списка товаров.

Клиент не обязан выбирать из длинного прайса.

Каталог — внутренняя база для AI и партнёров.

AI показывает готовый подарок: один дизайн сразу на нескольких изделиях.
