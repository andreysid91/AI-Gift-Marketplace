# Pricing System — система расчета цены

## Цель

Создать гибкую систему расчета стоимости заказа.

На первом этапе используются ориентировочные цены.

После появления партнеров цены заменяются на реальные.

---

# Формула цены

Цена клиента:

Производство

*

Материалы

*

Дизайн AI

*

Упаковка

*

Доставка

*

Комиссия сервиса

Цена показывается как:
