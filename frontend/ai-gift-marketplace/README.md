# AI Gift Marketplace

Добро пожаловать в проект **AI Gift Marketplace** — современный интернет-магазин подарков, разработанный с использованием технологий **React**, **Next.js** и **Tailwind CSS**. Этот проект вдохновлен современными стилями таких компаний, как Ozon, Apple и Airbnb, и предлагает пользователям интуитивно понятный интерфейс с акцентом на дизайн и удобство.

## Описание проекта

AI Gift Marketplace предоставляет пользователям возможность просматривать и приобретать подарки различных категорий. Проект включает в себя следующие ключевые компоненты:

- **Главная страница**: Отображает список доступных продуктов с возможностью фильтрации и поиска.
- **Страница продукта**: Позволяет пользователям просматривать детали конкретного продукта и добавлять его в корзину.
- **Корзина**: Пользователи могут просматривать добавленные товары и оформлять заказ.
- **Адаптивный дизайн**: Интерфейс оптимизирован для различных устройств, обеспечивая удобство использования на мобильных и десктопных платформах.

## Технологии

- **React**: Библиотека для создания пользовательских интерфейсов.
- **Next.js**: Фреймворк для серверного рендеринга и генерации статических сайтов.
- **Tailwind CSS**: Утилитарный CSS-фреймворк для быстрого создания пользовательских интерфейсов.

## Установка

1. Клонируйте репозиторий:
   ```
   git clone <URL>
   ```
2. Перейдите в директорию проекта:
   ```
   cd ai-gift-marketplace
   ```
3. Установите зависимости:
   ```
   npm install
   ```
4. Запустите проект:
   ```
   npm run dev
   ```
